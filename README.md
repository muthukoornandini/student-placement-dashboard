## 📖 Project Overview

The Student Placement Dashboard is a responsive front-end application developed using React.

The platform provides students with a centralized dashboard to:

- Explore placement opportunities
- Search and filter job openings
- Apply for available positions
- Track application status
- Manage interview schedules
- View placement statistics
- Monitor upcoming deadlines
- Receive placement notifications
- Manage their student profile

The project demonstrates the use of modern React concepts including reusable components, React Router, Hooks, Context API, form validation, and local storage.
